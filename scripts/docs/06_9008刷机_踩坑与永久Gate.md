# 9008 刷机踩坑与永久 Gate

## 当前最终架构

`zui072（9008）` 是 immutable original 072 母盘。只有通过 Golden/Release Gate 的
fixed-seven package 可进入 `zui072（flash）/out`。开发候选只在 `work/current`，
失败后提炼知识并删除大镜像。

## Owner / Authority

- candidate identity：显式 RunId + source commit + exact SHA manifest。
- bootability：final artifact ART Gate + Boot Hard Gate。
- flashed bytes：qdl `dump-part` 全长 SHA read-back，不是 ACK/flag。
- original source：`zui072（9008）/ORIGINAL_SHA256.txt`。

## 已淘汰设计

按目录时间/“最新”自动选包；在母盘内 build/extract；使用 full
rawprogram/patch XML；把 `--read-back-verify` 参数或 qdl ACK 当物理回读；Boot
FAIL 后连续 reboot 触发 RescueParty；为省空间临时删 system 预装 APK。

## 为什么错

自动选包会刷入 superseded candidate；full XML 可覆写 GPT/userdata/persist/FRP/
modemst；ACK 不证明分区全长数据一致；重复重启会放大救援转场；删预装
App 改变 product/runtime，不是 workspace 治理。

## 正确做法

只使用显式四镜像及 fixed-seven allowlist：`super`, `vbmeta_system_a/b`,
`boot_a/b`, `vbmeta_a/b`。禁止 GPT/userdata/persist/FRP/modemst/patch XML。刷前
核对 SHA，刷后七项全长 read-back；Boot Gate 失败就停止，一次采证后按已验证
恢复流程返回 Golden。Firehose 摘要未批准，qdl 速度 41–45MB/s 未解，
不在本阶段进 EDL。

## 禁止重新引入

`latest candidate`, `auto-discover B072`, `full rawprogram`, `patch XML`,
`ACK equals readback`, `retry reboot`, `delete system APK for space`。

## 必须阅读触发关键词

`9008`, `EDL`, `qdl`, `firehose`, `rawprogram`, `flash`, `super.img`, `read-back`,
`RescueParty`, `fixed-seven`。
