WHY THE OLD LOG HAD ZERO READ HANDLERS
The flasher path has no host read call. The flag requests loader-side behavior through an XML
attribute, whose implementation/coverage is opaque for this programmer. Therefore zero host
read handlers is expected from qdl-rs itself. RC0 and All went well prove ACKed programming,
not a host-observed byte/hash comparison.

NEW FAIL-CLOSED METHOD
1. flasher resets to EDL, not system;
2. qdl-rs dump-part reads each of super, vbmeta_system_a, vbmeta_system_b, boot_a, boot_b,
   vbmeta_a and vbmeta_b from the XML-declared UFS LUN;
3. host checks exact programmed byte length and SHA-256 against the approved image;
4. each 14GB/100MB/64KB temporary dump is deleted immediately after its hash is recorded;
5. only seven PASS results produce PHYSICAL_PARTITION_READBACK=PASS and allow reset system.
